# Root VPN — Backend (MVP)

این بک‌اند جایگزین واقعیِ منطقی‌ه که تا الان فقط تو جاوااسکریپت مرورگر
شبیه‌سازی شده بود: ثبت‌نام/ورود واقعی، ساخت سفارش با چند دستگاه، آپلود
واقعی رسید، و صف تایید برای ادمین.

## اجرا روی سیستم خودت (برای تست)

```bash
cd backend
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

بعدش برو به آدرس `http://127.0.0.1:8000/docs` — یه صفحه‌ی تعاملی خودکار
باز میشه که می‌تونی همه‌ی endpoint ها رو مستقیم از توش تست کنی، بدون
اینکه فرانت‌اند رو هم لازم داشته باشی.

پیش‌فرض از یه فایل SQLite محلی (`rootvpn.db`) استفاده می‌کنه، پس هیچ
دیتابیس جداگونه‌ای برای تست لازم نیست نصب کنی.

## چیزهایی که تا اینجا ساخته شده

- `models.py` — جدول‌های User / Order / OrderDevice / Receipt
- `pricing.py` — همون فرمول قیمت‌گذاری تایید‌شده‌ی فرانت‌اند، عیناً پورت‌شده
- `devices.py` — کاتالوگ دستگاه‌ها و قانون تخصیص خودکار پروتکل
- `auth.py` — هش کردن واقعی پسورد (bcrypt) + توکن نشست (JWT)
- `main.py` — endpoint های: ثبت‌نام، ورود، محاسبه‌ی قیمت، ساخت سفارش،
  آپلود رسید، لیست سفارش‌های خودم، صف سفارش‌های در انتظار برای ادمین

## چیزهایی که هنوز نساختیم (قدم‌های بعدی)

1. **احراز هویت ادمین جدا** — الان `/admin/orders/pending` بدون هیچ
   محافظتی در دسترسه. قبل از دیپلوی واقعی باید یه یوزر/پسورد یا نقش
   جدا برای ادمین اضافه بشه.
2. **endpoint تایید سفارش توسط ادمین** که وقتی زده میشه:
   - وضعیت سفارش رو `approved` کنه
   - برای هر دستگاه داخل سفارش، از طریق اسکریپت `gate_mikrotik_client.py`
     که قبلاً ساختیم، واقعاً روی میکروتیک اکانت بسازه
   - آدرس تخصیص‌یافته رو برگردونه تو دیتابیس ذخیره کنه
3. **وصل کردن فرانت‌اند واقعی** به این API به‌جای منطق فیک جاوااسکریپت
4. یه **Cron/job زمان‌بندی‌شده** که هر چند دقیقه چک کنه سفارش‌های منقضی‌شده
   رو غیرفعال کنه

هرکدوم از این‌ها آماده‌ای بریم سراغش بگو.
